# Stellara Roadmap

## Visão do Projeto

Stellara é um jogo 2D de exploração espacial inspirado em jogos como Escape Velocity Nova.

O jogador controla uma nave espacial, explora sistemas estelares, visita planetas e estações, negocia recursos, participa de combates e evolui sua nave.

O objetivo inicial não é criar um jogo completo, mas construir os sistemas fundamentais em camadas.

---

# Filosofia de Desenvolvimento

## Regras

- Cada versão deve adicionar uma mecânica completa.
- Evitar criar conteúdo antes dos sistemas existirem.
- Não criar dezenas de naves, planetas ou armas antes da base estar pronta.
- Priorizar sistemas reutilizáveis.
- Tudo que for possível deve ser orientado a dados.
