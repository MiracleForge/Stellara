# Stellara Roadmap

## Visão do Projeto

Stellara é um jogo 2D de exploração espacial, agricultura, construção e progressão.

O jogador começa preso em um planeta hostil com sua nave danificada.

O objetivo inicial é sobreviver, construir uma pequena base, produzir recursos e reparar a nave.

Depois, o jogador conquista acesso ao espaço e começa a explorar novos mundos, estações e regiões, utilizando os recursos encontrados para aumentar o alcance e a capacidade da nave.

### Loop principal

**Sobreviver → Construir → Cultivar → Minerar → Produzir → Reparar → Explorar → Descobrir → Melhorar → Alcançar novos mundos**

### Princípio central

> **A nave é permanente. Os mundos são temporários.**

---

# Filosofia de Desenvolvimento

## Regras

* Cada versão deve adicionar uma mecânica completa.
* Evitar criar conteúdo antes dos sistemas existirem.
* Validar os sistemas principais o mais cedo possível.
* Priorizar sistemas reutilizáveis.
* Tudo que for possível deve ser orientado a dados.
* A complexidade deve vir da combinação dos sistemas, não da quantidade de conteúdo.
* Criar poucos conteúdos representativos antes de expandir.
* Não criar dezenas de planetas, criaturas, naves ou itens antes da base estar pronta.
* O escopo inicial deve permanecer pequeno.
* Novas ideias devem ser classificadas antes de entrar no desenvolvimento.

# Critério para Novos Sistemas

Toda nova ideia deve ser classificada.

### A — Essencial

Necessária para a identidade do jogo.

→ Fazer.

### B — Fortalece

Melhora diretamente um sistema existente.

→ Considerar.

### C — Interessante

É legal, mas não é necessária.

→ Backlog.

### D — Outro jogo

Cria um sistema grande e independente que muda o foco do projeto.

→ Não fazer agora.

# Princípios de Escopo

## 1. O universo pode crescer sem aumentar a escala dos objetos

O jogo representa um universo grande através de:

* novos planetas;
* novos recursos;
* novos biomas;
* novas tecnologias;
* novos alcances.

Não através de sprites maiores ou mapas gigantes.

## 2. Cada novo planeta deve ter um propósito

Um planeta novo deve oferecer pelo menos uma combinação de:

* recurso;
* planta;
* criatura;
* tecnologia;
* ambiente;
* desafio;
* descoberta.

## 3. Cada recurso deve possuir propósito

```text
RECURSO
   ↓
PRODUÇÃO
   ↓
TECNOLOGIA
   ↓
PROGRESSÃO
```

Evitar recursos criados apenas para aumentar a quantidade de itens.

## 4. Cada upgrade importante deve expandir o jogo

Um upgrade importante deve permitir:

> **"Agora consigo chegar onde antes não conseguia."**

## 5. A base deve alimentar a nave

A progressão terrestre e espacial devem estar conectadas.

```text
BASE
 ↓
RECURSOS
 ↓
PRODUÇÃO
 ↓
NAVE
 ↓
EXPLORAÇÃO
 ↓
NOVOS RECURSOS
 ↓
NOVA BASE
```
